# Moving MNIST Dataset Visualization Scripts

This directory contains scripts for loading, analyzing, and visualizing the Moving MNIST dataset - a video dataset of bouncing MNIST digits.

## 📁 Files

### Core Scripts

- **`visualize_moving_mnist.py`** - Full-featured interactive visualization script with GUI support
- **`demo_moving_mnist.py`** - Non-interactive demo script that generates static visualizations

### Generated Output

- **`moving_mnist_demo_output/`** - Directory containing sample visualizations generated by the demo

## 🎬 Moving MNIST Dataset

The Moving MNIST dataset creates sequences of MNIST digits that bounce around a canvas with realistic physics. Key properties:

- **Digits**: 1-3 MNIST digits per sequence
- **Canvas**: 64x64 pixel canvas (configurable)
- **Movement**: Digits move with constant velocity and bounce off walls
- **Physics**: Deterministic or stochastic bouncing behavior
- **Format**: Sequences of grayscale images (seq_len, height, width, channels)

## ⚙️ Configuration Options

### Dataset Parameters

- `--seq_len`: Length of video sequences (default: 20)
- `--num_digits`: Number of digits per sequence (default: 2) 
- `--image_size`: Canvas size in pixels (default: 64)
- `--deterministic`: Use deterministic bouncing (default: False)
- `--data_root`: Directory for MNIST data (default: ./data)

### Visualization Options

- `--sample_index`: Which sample to visualize (default: 0)
- `--export`: Export sample data as files
- `--export_dir`: Directory for exported files (default: ./moving_mnist_samples)
- `--num_export`: Number of samples to export (default: 5)

## 🔧 Technical Details

### Data Format
- **Input**: Sequences of shape `(seq_len, height, width, channels)`
- **Values**: Float32 in range [0, 1] 
- **Channels**: 1 (grayscale)
- **Memory**: ~320 KB per 20-frame sequence

### Movement Physics
- **Velocity**: Random initial velocity (-4 to +4 pixels/frame)
- **Bouncing**: Elastic collisions with walls
- **Deterministic**: Velocity reverses on wall collision
- **Stochastic**: Random new velocity on wall collision

### Performance
- **Dataset size**: 60,000 training + 10,000 test samples
- **Loading time**: ~1-2 seconds for dataset initialization
- **Memory usage**: ~19 GB for full dataset (loaded on-demand)

## 📈 Integration with Signature Analysis

The Moving MNIST dataset is particularly useful for signature-based analysis:

```python
# Example: Extract path signatures from moving digit centers
from src.dataset.moving_mnist import MovingMNIST
import numpy as np

dataset = MovingMNIST(train=True, data_root='./data', seq_len=20)
sequence = dataset[0]  # Shape: (20, 64, 64, 1)

# Extract center of mass trajectory for signature analysis
def extract_trajectory(sequence):
    trajectories = []
    for t in range(sequence.shape[0]):
        frame = sequence[t, :, :, 0]
        # Find center of mass
        y_coords, x_coords = np.mgrid[0:frame.shape[0], 0:frame.shape[1]]
        total_mass = frame.sum()
        if total_mass > 0:
            center_y = (y_coords * frame).sum() / total_mass
            center_x = (x_coords * frame).sum() / total_mass
            trajectories.append([center_x, center_y])
    return np.array(trajectories)

trajectory = extract_trajectory(sequence)
# Now trajectory can be used with signature methods
```
